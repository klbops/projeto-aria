GUIA DE CONFIGURAÇÃO

Configure a ARIA em minutos

Siga os passos abaixo para obter suas credenciais do Telegram e Gemini
e montar o arquivo .env completo.

Passo 1 de 3
01
Criar o Bot no BotFather
fazer agora
1
Abra o Telegram e procure por @BotFather (verificado, tem o selo azul)
🔗 t.me/BotFather
2
Envie o comando /newbot
/newbotclique para copiar
3
O BotFather vai pedir o nome de exibição do bot (pode ter espaços)
ARIA Pessoalclique para copiar
4
Depois vai pedir o username (sem espaço, deve terminar em "bot")
aria_meu_assistente_botclique para copiar
5
O BotFather vai responder com o token — algo assim:
Resposta do BotFather: Done! Congratulations on your new bot.
Use this token to access the HTTP API:
110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
Keep your token secure and store it safely.
02
Salvar o Token do Bot
cole aqui
💡
O token tem o formato 123456789:ABCdef... — números, dois pontos, letras e números.
TELEGRAM_BOT_TOKEN
03
Descobrir seu Chat ID
fazer agora
1
No Telegram, procure pelo username do seu bot (o que você escolheu acima) e envie qualquer mensagem — pode ser "oi"
2
Abra esta URL no navegador (substitua TOKEN pelo seu token):
https://api.telegram.org/botSEU_TOKEN/getUpdates clique para abrir
3
No JSON que aparecer, procure por "chat" → "id" — esse é seu Chat ID
Exemplo de resposta do getUpdates: {"ok":true,"result":[{"message":{
  "chat":{
    "id": 987654321,
    "first_name": "Kleber",
    "type": "private"
  }
}}]}
4
Alternativa mais fácil: envie uma mensagem para @userinfobot — ele responde seu ID automaticamente
🔗 t.me/userinfobot
TELEGRAM_CHAT_ID
01
Acessar o Google AI Studio
gratuito
✅
O Gemini tem um plano gratuito generoso — suficiente para uso pessoal diário. Não precisa de cartão de crédito.
1
Acesse o Google AI Studio com sua conta Google
🔗 aistudio.google.com/app/apikey
2
Clique em "Create API Key" (botão azul no topo)
3
Selecione "Create API key in new project"
4
Copie a chave gerada — começa com AIzaSy...
Exemplo de API Key: AIzaSyD4xK2mN8pQ3rT6vW9xZ1bC5eF7hI0jL2
⚠️ Copie agora — não será exibida novamente
02
Salvar a API Key do Gemini
cole aqui
⚠️
Nunca compartilhe sua API Key. Não coloque ela em repositórios públicos no GitHub.
GEMINI_API_KEY

02
Colar no VPS e subir
comandos
1
No VPS, entre na pasta do projeto e crie o .env
cd aria && nano .envclique para copiar
2
Cole o conteúdo acima, salve com Ctrl+O → Enter → Ctrl+X
3
Suba os containers
docker compose up -dclique para copiar
4
Acompanhe os logs — deve aparecer 🤖 Telegram Bot iniciado
docker compose logs -f backendclique para copiar
5
Abra o Telegram, mande /start para o seu bot e teste!
